2. What the app does

GX Launcher is a launcher for your own game collection. It scans a folder you choose, shows the games it finds with covers and, on request, starts an emulator you have installed. The app contains no games and no emulators.

3. Data stored locally

Stored only on your device:

  • the game list (file names, titles, game IDs, region, file size),
  • downloaded cover images and cheat lists,
  • settings, theme, favourites, collections and play time.

This data never leaves your device and is not visible to me.

4. File access

To find your games, the app needs access to the folder that contains your game files. Files are only read to recognise title and game ID. When you start a game, the file is passed to the chosen emulator via a protected content address.

5. Covers and cheats from the internet

For missing covers and cheat lists, the app requests public files directly from these providers:

  • GameTDB (art.gametdb.com, www.gametdb.com) – covers and game information,
  • libretro thumbnails (thumbnails.libretro.com) – covers,
  • GitHub (raw.githubusercontent.com, api.github.com) – cheat lists,
  • RiiConnect24 (codes.rc24.xyz) – Wii/GameCube cheat lists.

For technical reasons, each provider receives your IP address and the name of the requested file (for example a game ID). No other data such as accounts or advertising IDs is sent. The privacy policies of these providers apply.

6. No tracking, no ads, no purchases

The app contains no advertising, analytics or crash reporting services and no in-app purchases.

7. Legal basis

Processing takes place to provide the app functions (Art. 6(1)(b) GDPR). Covers and cheats are only requested when you use these features.

8. Retention and deletion

All data stays on your device until you uninstall the app or clear its data in the system settings. You can also clear the cover cache in the app settings.

9. Your rights

Under the GDPR you have the right to access, rectification, erasure, restriction of processing and to lodge a complaint with a supervisory authority. As I do not store any personal data about you, I can usually only confirm that no data exists.

10. Changes

This policy will be updated when the app changes. The current version applies.

11. This website

The GX Launcher website is hosted on GitHub Pages (GitHub, Inc., USA). When you visit it, GitHub processes technically necessary data such as IP address, time and requested file to deliver and secure the site (Art. 6(1)(f) GDPR). GitHub is certified under the EU-US Data Privacy Framework. The website uses no cookies and no analytics or advertising services.
