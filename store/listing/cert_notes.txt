runFullTrust: GX Launcher is a desktop game-library frontend built with Electron (packaged as a full-trust Win32 desktop app via MSIX). It needs full trust to scan the user's own game folders on any drive, to start the emulator programs the user has chosen (e.g. Dolphin, RetroArch) with the selected game, and to read/write emulator save files and memory cards the user selects. The app contains no games, ROMs, BIOS files or emulators.

Notes for certification: In-app purchases (subscriptions gx_premium_monat / gx_premium_jahr, durable add-ons gx_lifetime and design packs) use Windows.Services.Store via the bundled helper resources\store\GXStore.exe. All core features are free and work without purchase. To test: start the app, choose any folder (an empty folder is fine) as game folder, open the side menu → "Premium freischalten" to see the Store offers.
